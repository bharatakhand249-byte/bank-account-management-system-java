# Project Statement

## Project Title

**Bank Account Management System**

## 1. Problem Statement

Managing basic bank-account activities manually can make it difficult to maintain account records, validate transactions, calculate balances, and review transaction history consistently.

The proposed Bank Account Management System is a console-based Java application that provides a structured way to simulate account creation, account management, deposits, withdrawals, transfers, transaction history, and reporting.

The system is designed as an academic simulation and does not connect to real banking infrastructure.

## 2. Scope

The project covers:

- Savings and current account creation
- Account search and listing
- Account closing
- Deposits and withdrawals
- Transfers between accounts
- Transaction history
- Reports and summaries
- CSV-based local persistence
- Input validation and exception handling

The project does not cover real banking networks, real payments, online authentication, or production financial security.

## 3. Target Users

- Students learning Java
- Faculty evaluating Java OOP concepts
- Users demonstrating a basic banking simulation

## 4. High-Level Features

- Create Savings Account
- Create Current Account
- Display Accounts
- Search Account
- Deposit
- Withdraw
- Transfer
- Transaction History
- Reports
- Save/Load Data
- Close Account
- Validation and exception handling

## 5. Technical Approach

The system uses Java Standard Library classes and a package-based architecture. Account types use inheritance from an abstract base class. Collections maintain accounts and transactions. File I/O provides CSV persistence.

No external libraries or database applications are required.
